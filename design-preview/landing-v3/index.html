    Why it is private

    The upload step does not exist.

    Every tool is JavaScript running in your own tab. There is no server to send your file to, which is why there is no account, no queue and no retention policy.

    01

    No servers

    Your text, PDFs and images are read, processed and written back out by the browser. Nothing is transmitted.

    02

    No accounts

    There is no server-side state to attach an account to, so there is no sign-up, no email wall and no trial.

    03

    No waiting

    No round trip means results appear as fast as your own machine can compute them, and file size is capped by your device, not our plan.

    Questions

    Before you start.

    Are all the tools free?+
    Yes — all 234 tools across all 11 suites, with no premium tier and no per-file limits. The site is supported by advertising, not by charging for the tools.
    Is my data uploaded to a server?+
    Never. All tools run in your browser using JavaScript. Your text, files and data do not leave your device, so there is nothing for us to store or log.
    Do the tools work on mobile?+
    Yes. Every tool is responsive, and the file-based ones use the standard mobile file picker, so PDFs and photos from your camera roll behave exactly as they do on desktop.
    Do I need to install anything?+
    No. There is no app, no browser extension and no dependency to install. Open the page and the tool is ready.
    Can I use the tools offline?+
    Most keep working once the page has loaded, because the processing is already on your device. The exceptions are the few that call an external service, such as certain text-to-speech voices.
